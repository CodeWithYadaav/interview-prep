String and Array Manipulation Questions:
Anagrams:

Write a function to check if two strings are anagrams of each other.
Return the Character with Maximum Occurrences from a String:

Given a string, write a function to return the character that appears most frequently.
Return the Index of a Target in an Array:

Given an array and a target value, write a function to return the index of the target. If it’s not found, return -1.
Count of Maximum Value in an Array:

Write a function to count how many times the maximum value appears in an array.
Return the Minimum Number of Characters from a String:

Write a function that returns the minimum number of characters from a given string to ensure all characters are unique.
Sorting an Array of Objects:

Write a function that sorts an array of objects by a specific property, such as age.


ARRAYS-------------------->

1. Find the Maximum and Minimum:
Write a function to find the maximum and minimum elements in an array.

2. Reverse an Array:
Write a function that reverses an array in place.

Remove Duplicates from Sorted Array:
Write a function that removes duplicates from a sorted array and returns the new length.

Rotate Array:
Write a function to rotate an array by k steps to the right.

Find Pair with Given Sum:
Write a function that finds a pair of numbers in an array that adds up to a specific target sum.

Merge Two Sorted Arrays:
Write a function that merges two sorted arrays into one sorted array.

Move Zeroes:
Write a function that moves all zeroes in an array to the end while maintaining the order of other elements.

Find Missing Number:
Write a function to find the missing number in a sequence of numbers from 1 to n.

Find Duplicates:
Write a function that finds all duplicate numbers in an array.

Find Intersection of Two Arrays:
Write a function that finds the intersection of two arrays.

Find the Largest Sum Contiguous Subarray:
Implement Kadane’s Algorithm to find the largest sum of a contiguous subarray.

Subarray with Given Sum:
Write a function that finds a subarray with a given sum in a non-negative array.

Find the Second Largest Element:
Write a function to find the second largest element in an array.

Product of Array Except Self:
Write a function that returns an array where each element is the product of all the elements of the input array except itself, without using division.

Maximum Product Subarray:
Write a function to find the contiguous subarray within an array that has the largest product.

Merge Intervals:
Write a function that merges overlapping intervals in an array of intervals.

Find the First Missing Positive:
Write a function to find the first missing positive integer in an array.

Find the Longest Consecutive Sequence:
Write a function that finds the length of the longest consecutive elements sequence.

Find Common Elements in Three Sorted Arrays:
Write a function to find common elements in three sorted arrays.

Array Partitioning:
Write a function to partition an array such that all elements smaller than a pivot appear before elements larger than the pivot.

Find Median of Two Sorted Arrays:
Write a function to find the median of two sorted arrays of possibly different sizes.

Check if Array is Sorted and Rotated:
Write a function to check if an array is sorted and then rotated.

Majority Element:
Write a function that finds the majority element in an array (the element that appears more than ⌊n/2⌋ times).

Find Peak Element:
Write a function to find a peak element in an array (an element that is greater than its neighbors).






STRINGS--------------->

Count Character Occurrences:
Write a function that counts the occurrences of each character in a given string and returns an object with the character counts.

Find Max Occurrence Character:
Write a function that finds and returns the character with the highest occurrence in a given string.

First Non-Repeating Character:
Write a function that finds and returns the first non-repeating character in a string. If all characters repeat, return null.

Check for Anagrams:
Write a function that checks if two given strings are anagrams (i.e., if they contain the same characters in different orders).

Reverse a String:
Write a function that reverses a given string without using built-in reverse functions.

Count Vowels and Consonants:
Write a function that counts the number of vowels and consonants in a given string and returns an object with the counts.

Longest Substring Without Repeating Characters:
Write a function that finds the length of the longest substring in a given string that does not contain any repeating characters.

Check for Palindrome:
Write a function that checks if a given string is a palindrome (i.e., it reads the same forwards and backwards).

Character Replacement:
Write a function that replaces all occurrences of a specified character in a string with another character.

Find Most Frequent Word:
Write a function that finds and returns the most frequent word in a given sentence. Consider words to be separated by spaces and ignore punctuation.

Remove Duplicate Characters:
Remove repeated characters from a string. For example, "aabbcc" becomes "abc".

String Compression:
Implement basic compression by replacing consecutive repeated characters with the character followed by the count. Handle edge cases where the compressed version isn't shorter.

Permutations of a String:
Generate and list all possible permutations of the string's characters.

String Rotation:
Check if one string can be rotated to become another. This can often be solved by checking if the second string is a substring of the first string concatenated with itself.

Longest Palindromic Substring:
Find the longest substring that reads the same forwards and backwards.

Remove a Specific Character:
Iterate over the string, skipping the character that needs to be removed, and rebuild the string without it.

Find All Anagrams in a String:
Use sliding window and frequency counting techniques to find all anagrams of a string within another string.

Capitalize Words:
Transform a sentence such that each word begins with an uppercase letter.

Check for Subsequence:
Determine if all characters in one string appear in the same order in another string, without rearrangement.

String Interleaving:
Verify if a string can be created by interleaving two other strings while preserving the character order in each.
