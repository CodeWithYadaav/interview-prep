🧱 1. MSA Fundamentals & Design

| Question                                                         | What they expect                                                 |
| ---------------------------------------------------------------- | ---------------------------------------------------------------- |
| What is microservices architecture?                              | Clear contrast with monolith, focus on independent deployability |
| Why do companies move from monolith to microservices?            | Real-world pain points like scaling, code ownership              |
| How do you split a monolith into microservices?                  | Realistic domain decomposition (e.g., users, orders, payments)   |
| What is bounded context in microservices?                        | Explain via DDD or business logic ownership                      |
| Can you explain CAP Theorem and how it applies to microservices? | Quick grasp of consistency vs availability tradeoffs             |


🧭 2. Communication Between Services

| Question                                         | What they expect                                   |
| ------------------------------------------------ | -------------------------------------------------- |
| How do microservices communicate?                | REST, gRPC, message queues (Kafka/RabbitMQ)        |
| When would you use sync vs async communication?  | E.g., GET order = sync; order placed event = async |
| What is API Gateway and how does it help in MSA? | Central routing, auth, rate limit, caching         |
| How do you version APIs in microservices?        | URL vs header-based versioning                     |
| Have you used service discovery?                 | Talk about Consul, Eureka, or K8s service registry |


🔁 3. Data Management

| Question                                                       | What they expect                                |
| -------------------------------------------------------------- | ----------------------------------------------- |
| Should each microservice have its own DB? Why?                 | Yes – decoupling and ownership                  |
| How do you handle transactions across services?                | Saga pattern (orchestrator/choreography) vs 2PC |
| What are eventual consistency challenges?                      | Talk about delay, retries, compensating actions |
| How to handle queries that span multiple services (reporting)? | Data duplication / CQRS / data warehouse        |
| How do you keep data in sync across services?                  | Change Data Capture (CDC), events, Kafka        |


⚠️ 4. Reliability, Failure Handling


| Question                                         | What they expect                                    |
| ------------------------------------------------ | --------------------------------------------------- |
| What happens if one service is down?             | Circuit breaker (e.g., with Resilience4j)           |
| Explain retry, backoff, circuit breaker patterns | Real use case: payment, API call failures           |
| How do you ensure fault isolation?               | Deployment isolation + containerization             |
| What is the role of timeouts in microservices?   | Prevent thread blocking and cascading failures      |
| How do you handle network failures?              | Timeouts, retries, async queues, fallback responses |



🔐 5. Security in Microservices

| Question                                                         | What they expect                               |
| ---------------------------------------------------------------- | ---------------------------------------------- |
| How do you implement authentication?                             | JWT/OAuth via API Gateway or auth service      |
| What is the difference between authentication and authorization? | Real-world access control scenario             |
| How do you secure inter-service communication?                   | mTLS, service mesh (Istio/Linkerd), API tokens |
| How do you prevent man-in-the-middle or replay attacks?          | JWT expiry, nonce, TLS                         |
| How to implement role-based access in MSA?                       | Enforce at API Gateway or per service level    |


🚀 6. Deployment & CI/CD

| Question                                                     | What they expect                                        |
| ------------------------------------------------------------ | ------------------------------------------------------- |
| How do you deploy microservices independently?               | Docker + CI/CD pipelines                                |
| Have you worked with Docker and Kubernetes?                  | Talk about deployment, service, autoscaling             |
| How do you handle rolling updates or blue-green deployments? | Canary/blue-green via CI or K8s strategies              |
| What is service mesh? Why is it used?                        | Observability, traffic control, security (Envoy, Istio) |
| How to rollback a failed service update?                     | CI/CD rollback + version pinning                        |


📊 7. Monitoring & Observability

| Question                                           | What they expect                                  |
| -------------------------------------------------- | ------------------------------------------------- |
| How do you trace requests across services?         | Distributed tracing (e.g., OpenTelemetry, Jaeger) |
| What tools do you use for monitoring/logging?      | Prometheus, Grafana, ELK, Loki, Datadog           |
| How do you handle log correlation?                 | Trace ID / Correlation ID in headers              |
| How do you set service-level alerts?               | Custom metrics, alert thresholds, dashboards      |
| How do you debug an issue in a microservice chain? | Explain tracing flow with logs + metrics          |



🔄 8. Async Messaging & Kafka

| Question                                           | What they expect                                       |
| -------------------------------------------------- | ------------------------------------------------------ |
| When do you use Kafka vs REST?                     | Fire-and-forget, event sourcing, decoupling            |
| How does Kafka ensure message durability?          | Log retention, commit log, partitions                  |
| What is the difference between Kafka and RabbitMQ? | Kafka = log-based, pub-sub; RabbitMQ = queue-based     |
| How do you guarantee at-least-once delivery?       | Consumer offset management                             |
| How do you handle idempotency in consumers?        | Track processed message IDs or use deduplication logic |
