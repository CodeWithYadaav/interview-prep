KEY POINTS TO EXPLAIN:

1. IDEMPOTENCY (Critical!)
   "We use idempotency keys to prevent duplicate charges"

   Example:
   - Client sends: POST /payments with idempotency-key: "abc123"
   - If network fails and client retries with same key
   - System checks: "Already processed abc123" → Return same response
   - No duplicate charge!

2. SAGA PATTERN for Distributed Transaction

   Step 1: Create Order (status: PENDING)
   Step 2: Reserve Inventory
   Step 3: Process Payment
   Step 4: Update Order (status: CONFIRMED)

   If Step 3 fails:
   - Compensate Step 2: Release inventory
   - Compensate Step 1: Cancel order

   "We use orchestration-based Saga with a coordinator service"

3. ASYNC NOTIFICATIONS
   "After payment success, we publish event to Kafka"
   - Notification service consumes event
   - Sends email/SMS asynchronously
   - Doesn't block payment flow

4. RETRY & CIRCUIT BREAKER
   "Payment gateway calls have retry with exponential backoff"
   - Try 1: Immediate
   - Try 2: After 2 seconds
   - Try 3: After 4 seconds
   - If all fail: Circuit breaker opens, return error

CODE EXAMPLE:
```javascript
async function processPayment(orderId, amount, idempotencyKey) {
  // 1. Check idempotency
  const existing = await checkIdempotency(idempotencyKey);
  if (existing) return existing;

  // 2. Start Saga
  const sagaId = await startSaga();

  try {
    // 3. Reserve inventory
    await inventoryService.reserve(orderId);

    // 4. Charge payment
    const payment = await paymentGateway.charge(amount);

    // 5. Confirm order
    await orderService.confirm(orderId);

    // 6. Publish event
    await kafka.publish('payment.success', { orderId, payment });

    // 7. Store idempotency result
    await storeIdempotency(idempotencyKey, payment);

    return payment;

  } catch (error) {
    // Compensate: Rollback inventory
    await inventoryService.release(orderId);
    await orderService.cancel(orderId);
    throw error;
  }
}
```

"I would use the Strangler Fig pattern - gradually replace parts of monolith"

1. IDENTIFY BOUNDARIES
   "First, analyze the monolith and identify bounded contexts"
   - User management (authentication, profiles)
   - Order management (cart, checkout)
   - Product catalog (search, details)
   - Payment processing
   - Notifications

2. PRIORITIZE EXTRACTION
   "Start with services that have:"
   - Clear boundaries
   - Least dependencies
   - High change frequency
   - Performance bottlenecks

   Example: "I'd start with User Service - it's independent"

3. CREATE FACADE/ADAPTER
   "Use API Gateway to route requests"

5. HANDLE SHARED CODE
   "Extract common code to shared libraries"
   - But avoid tight coupling
   - Each service can have its own copy if needed

THE INVENTORY PROBLEM:

"Two users trying to buy last item simultaneously"

User A: "Buy iPhone" (1 left)
User B: "Buy iPhone" (1 left)

❌ WITHOUT PROPER HANDLING:
Both see "1 available" → Both place order → Oversold!

✅ WITH RESERVATION PATTERN:

FLOW:
1. User adds to cart → RESERVE inventory (not sold yet)
2. Reserved for 10 minutes
3. User completes payment → CONFIRM reservation → Reduce stock
4. If timeout → RELEASE reservation → Stock available again

DATABASE SCHEMA:

Inventory Table:
┌────────────┬───────────┬──────────┐
│ product_id │ available │ reserved │
├────────────┼───────────┼──────────┤
│ iPhone-15  │    5      │    2     │
└────────────┴───────────┴──────────┘
Total Stock = available + reserved = 7
Can sell = available = 5

Reservations Table:
┌────────────┬────────────┬───────────┬──────────┐
│ reservation│ product_id │ quantity  │ expires  │
├────────────┼────────────┼───────────┼──────────┤
│ res-123    │ iPhone-15  │    1      │ 10:30 AM │
│ res-456    │ iPhone-15  │    1      │ 10:35 AM │
└────────────┴────────────┴───────────┴──────────┘

CODE EXAMPLE:
```javascript
// 1. Reserve Inventory
async function reserveInventory(productId, quantity) {
  const inventory = await db.query(
    'SELECT available FROM inventory WHERE product_id = ? FOR UPDATE',
    [productId]
  );

  if (inventory.available < quantity) {
    throw new Error('Out of stock');
  }

  // Create reservation
  const reservationId = generateId();
  const expiresAt = Date.now() + 10 * 60 * 1000; // 10 min

  await db.transaction(async (tx) => {
    // Reduce available, increase reserved
    await tx.query(
      'UPDATE inventory SET available = available - ?, reserved = reserved + ? WHERE product_id = ?',
      [quantity, quantity, productId]
    );

    // Create reservation record
    await tx.query(
      'INSERT INTO reservations (id, product_id, quantity, expires_at) VALUES (?, ?, ?, ?)',
      [reservationId, productId, quantity, expiresAt]
    );
  });

  return reservationId;
}

// 2. Confirm Reservation (after payment)
async function confirmReservation(reservationId) {
  await db.transaction(async (tx) => {
    const reservation = await tx.query(
      'SELECT * FROM reservations WHERE id = ?',
      [reservationId]
    );

    // Move from reserved to sold
    await tx.query(
      'UPDATE inventory SET reserved = reserved - ? WHERE product_id = ?',
      [reservation.quantity, reservation.product_id]
    );

    // Delete reservation
    await tx.query('DELETE FROM reservations WHERE id = ?', [reservationId]);
  });
}

// 3. Release Expired Reservations (Background Job)
async function releaseExpiredReservations() {
  const expired = await db.query(
    'SELECT * FROM reservations WHERE expires_at < NOW()'
  );

  for (const reservation of expired) {
    await db.transaction(async (tx) => {
      // Return to available
      await tx.query(
        'UPDATE inventory SET available = available + ?, reserved = reserved - ? WHERE product_id = ?',
        [reservation.quantity, reservation.quantity, reservation.product_id]
      );

      await tx.query('DELETE FROM reservations WHERE id = ?', [reservation.id]);
    });
  }
}

// Run every minute
setInterval(releaseExpiredReservations, 60 * 1000);
```

EVENTUAL CONSISTENCY:
"Inventory updates are eventually consistent across services"
- Order service publishes 'order.created' event
- Inventory service listens and updates stock
- If event processing fails, retry with dead letter queue

   ```javascript
   async function sendEmail(notification) {
     const maxRetries = 3;
     let attempt = 0;

     while (attempt < maxRetries) {
       try {
         await emailProvider.send(notification);
         await markAsDelivered(notification.id);
         return;
       } catch (error) {
         attempt++;

         if (attempt === maxRetries) {
           // Move to dead letter queue
           await dlq.push(notification);
           await markAsFailed(notification.id);
         } else {
           // Exponential backoff
           await sleep(Math.pow(2, attempt) * 1000);
         }
       }
     }
   ```

   ```javascript
   async function getMessages(roomId, userId, cursor = null, limit = 50) {
     // Verify access
     const hasAccess = await checkRoomAccess(userId, roomId);
     if (!hasAccess) throw new Error('Access denied');

     // Cursor-based pagination
     let query = `
       SELECT * FROM messages
       WHERE room_id = ?
     `;
     const params = [roomId];

     if (cursor) {
       query += ` AND created_at < ?`;
       params.push(cursor);
     }

     query += ` ORDER BY created_at DESC LIMIT ?`;
     params.push(limit);

     const messages = await db.query(query, params);

     return {
       messages: messages.reverse(),
       nextCursor: messages.length > 0
         ? messages[0].created_at
         : null
     };
   }
   ```

   ```javascript
   const Queue = require('bull');
   const queue = new Queue('image-processing', {
     redis: { host: 'redis', port: 6379 }
   });

   queue.process(async (job) => {
     const { jobId, userId, images } = job.data;

     try {
       // Update status to processing
       await db.query(
         `UPDATE jobs SET status = 'processing', started_at = NOW()
          WHERE id = ?`,
         [jobId]
       );

       let completed = 0;
       const results = [];

       // Process each image
       for (const image of images) {
         try {
           // Actual processing
           const result = await processImage(image);
           results.push(result);
           completed++;

           // Update progress
           await db.query(
             `UPDATE jobs SET completed_items = ? WHERE id = ?`,
             [completed, jobId]
           );

           // Report progress (for real-time updates)
           job.progress(completed / images.length * 100);

         } catch (error) {
           console.error(`Failed to process image ${image}:`, error);
           results.push({ image, error: error.message });
         }
       }

       // Mark as completed
       await db.query(
         `UPDATE jobs
          SET status = 'completed',
              result = ?,
              completed_at = NOW()
          WHERE id = ?`,
         [JSON.stringify(results), jobId]
       );

       // Send notification
       await notificationService.send(userId, {
         type: 'job-completed',
         jobId,
         message: `Processed ${completed}/${images.length} images`
       });

       return results;

     } catch (error) {
       // Mark as failed
       await db.query(
         `UPDATE jobs
          SET status = 'failed',
              error = ?,
              completed_at = NOW()
          WHERE id = ?`,
         [error.message, jobId]
       );

       throw error;
     }
   });
   ```

```javascript
async function pollJobStatus(jobId) {

  let attempts = 0;

  while (attempts < maxAttempts) {
    const response = await fetch(`/api/jobs/${jobId}`);

    console.log(`Progress: ${job.progress.percentage}%`);

    if (job.status === 'completed') {
      console.log('Job completed!', job.result);
      return job;
    }

    if (job.status === 'failed') {
      throw new Error(job.error);
    }

    // Wait 5 seconds before next poll
    await new Promise(resolve => setTimeout(resolve, 5000));
    attempts++;

}
```
