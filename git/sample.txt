
🔧 1. What does git stash do?
git stash            # Save current changes
git stash list       # View stashed changes
git stash pop        # Apply and remove the latest stash
git stash apply      # Apply but keep the stash


2. How to delete a stash?
git stash drop stash@{0}   # Delete specific stash
git stash clear            # Delete all stashes



🔄 3. What is git rebase and when to use it?
Purpose: Move or combine a sequence of commits to a new base commit.

git checkout feature
git rebase main

✅ Use when:
You want a cleaner linear history
You want to integrate latest changes from main




🎯 4. Difference between rebase and merge

| Feature      | `merge`               | `rebase`                  |
| ------------ | --------------------- | ------------------------- |
| History      | Preserves all commits | Linear, rewritten history |
| Merge commit | Yes                   | No                        |
| Use case     | Collaboration         | Clean feature branches    |



📦 5. What is git squash and how to do it?
Squashing means combining multiple commits into one.


git rebase -i HEAD~3
# Change 'pick' to 'squash' for the last 2 commits



✅ Use case: Clean up commit history before merging to main.






🧠 6. What is git reflog?
Tracks all changes to HEAD — even unreachable commits (safe recovery tool).

git reflog          # Show all moves of HEAD
git checkout <hash> # Recover a lost commit



✅ Use case: Recover commits after a reset or accidental delete.



🔥 7. How to delete a specific commit?

(A) Delete latest commit (un-pushed)

git reset --hard HEAD~1     # Deletes last commit and changes
git reset --soft HEAD~1     # Deletes commit but keeps changes staged



(B) Delete middle commit (interactive)
git rebase -i HEAD~5        # Change `pick` to `drop`



🚫 8. How to revert a pushed commit?
Revert by commit hash:
git revert <commit_hash>       # Creates a new commit that undoes the changes
git push origin main


✅ Best for public/shared branches (non-destructive).



❌ 9. How to undo a pushed commit permanently (dangerous)?
If commit is already pushed and you want to delete history:

git reset --hard <commit_hash>
git push origin main --force   # ⚠️ Force push (use only if team agrees)

✅ Used with caution! Not safe for shared repos unless you coordinate.




🔄 10. How to revert a commit by message?


git log --grep="Your message"  # Find commit hash
git revert <commit_hash>



⏪ 11. Undo a commit that is NOT pushed yet
git reset --soft HEAD~1    # Keep your changes staged
git reset --mixed HEAD~1   # Keep your changes unstaged
git reset --hard HEAD~1    # Remove commit and changes


💥 BONUS: What does git cherry-pick do?
Copy a specific commit from another branch.

git cherry-pick <commit_hash>

✅ Use case: You want to apply a bugfix from one branch into another.




| Task                             | Command                              |
| -------------------------------- | ------------------------------------ |
| Stash changes                    | `git stash`                          |
| Rebase with squash               | `git rebase -i HEAD~n`               |
| Undo pushed commit               | `git revert <hash>`                  |
| Delete unpushed commit           | `git reset --soft/mixed/hard HEAD~1` |
| Recover lost commit              | `git reflog` + `git checkout`        |
| Apply a commit to another branch | `git cherry-pick <hash>`             |
