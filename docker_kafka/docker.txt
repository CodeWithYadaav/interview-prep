🔹 1. What is Docker and why is it used?

Docker is a platform for developing, shipping, and running applications in isolated environments called containers.
It allows developers to package applications along with their dependencies, ensuring consistency across environments (dev, test, prod).


🔹 2. What is the difference between Docker containers and virtual machines (VMs)?
| Docker Container      | Virtual Machine         |
| --------------------- | ----------------------- |
| Lightweight           | Heavyweight             |
| Shares host OS kernel | Has its own OS          |
| Starts in seconds     | Takes minutes to boot   |
| Uses less memory      | Requires more resources |



🔹 3. What are the basic Docker components?

Dockerfile: Instructions to build a Docker image.
Docker Image: Blueprint of the application environment.
Docker Container: Running instance of an image.
Docker Hub: Registry of Docker images.
Docker Compose: Tool to run multi-container applications.


🔹 4. How do you create a Docker image for a Node.js app?

# Dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "index.js"]


Then build and run:
docker build -t my-node-app .
docker run -p 3000:3000 my-node-app



🔹 5. How do you persist data in Docker containers?

----->Use volumes or bind mounts.
docker run -v mydata:/app/data my-node-app

This persists /app/data even if the container is destroyed.



🔹 6. What is the difference between COPY and ADD in Dockerfile?

COPY: Copies files/directories from the host.
ADD: Same as COPY + can unpack .tar files and download URLs.
Prefer COPY unless you specifically need ADD's extra features.



 7. How do you connect containers together?

Via a Docker network.
With Docker Compose, it's easier.

Example (docker-compose.yml):
version: '3'
services:
  app:
    build: .
    ports:
      - "3000:3000"
    depends_on:
      - db
  db:
    image: postgres
    environment:
      POSTGRES_PASSWORD: example


In the Node.js code, you can access DB via db:5432.


🔹 8. How do you reduce Docker image size?

Use multi-stage builds.
Use lightweight base images (e.g., node:alpine).
Remove unnecessary files.
Use .dockerignore to skip copying files like node_modules.


🔹 9. What happens when you run docker-compose up?

Reads docker-compose.yml.
Builds images if needed.
Creates a default network.
Starts all defined containers.
Attaches logs to your terminal.



🔹 10. How do you debug a running container?

docker exec -it <container_id> /bin/sh

docker logs <container_id>
