// Generics in TypeScript are a way to create reusable components that can work with any type while maintaining strong type safety. Instead of specifying a specific type up front, you define a placeholder (often called T for "type") that gets replaced with a concrete type when the function, class, or interface is used.

// Generics allow for flexibility in code while still enforcing type checks, ensuring that functions or classes can work with different types without losing type safety.


// Type Safety: They ensure that operations performed on a type are valid for that type.
// Reusability: They allow the same function or class to handle different types, avoiding code duplication.
// Flexibility: You can work with different types while still enforcing constraints.



✅ Q: Write a generic function that accepts an array of any type and returns the first element of the array.

function getFirstElement<T>(arr: T[]): T | undefined {
  return arr[0];
}

// Usage examples:
const firstNumber = getFirstElement<number>([1, 2, 3]); // 1
const firstString = getFirstElement<string>(["a", "b", "c"]); // "a"

T is a type placeholder.
The function returns T | undefined in case the array is empty.





✅ Q: Can you have multiple generics in a TypeScript function? If so, provide an example.

Yes, you can have multiple generic type parameters, separated by commas.


function pair<T, U>(first: T, second: U): [T, U] {
  return [first, second];
}

// Usage examples:
const numberStringPair = pair<number, string>(1, "one"); // [1, "one"]
const booleanArrayPair = pair<boolean, number[]>(true, [1, 2, 3]); // [true, [1, 2, 3]]

T and U are two generic types.
This is useful when working with tuples, key-value pairs, or mixed-type data.




✅ Bonus: Generic Constraints

You can also constrain generics to ensure they follow certain structure.

function logLength<T extends { length: number }>(item: T): void {
  console.log(item.length);
}

logLength("Hello"); // OK, string has length
logLength([1, 2, 3]); // OK, array has length
// logLength(123); ❌ Error: number doesn’t have length
